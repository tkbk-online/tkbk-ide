# tkbk-welcome

Встроенное расширение TKBK IDE: страница «Начало работы», первый запуск
(установка комплекта расширений из `resources/app/bundled-extensions`,
включение русского интерфейса), пошаговое знакомство, пункт «TKBK» в строке состояния.

Ссылки берутся из `product.json` → `tkbk` (homepage, login, buy, docs, skills).
