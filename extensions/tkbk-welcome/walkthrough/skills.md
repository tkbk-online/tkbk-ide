## Скилы и MCP TKBK

- **Skills Hub** — github.com/tkbk-online/skills: 59 проверенных скилов для Wildberries, Ozon, Яндекс Маркета, Bitrix24, amoCRM, Avito, ЮKassa/СБП и документов по РФ.
- **MCP-серверы** — github.com/tkbk-online/tkbk-mcp: маркетплейсы, CRM, Директ, Метрика, Вебмастер, DaData.

Установка скила в проект: `npx skills add tkbk-online/skills --skill <имя>`.
